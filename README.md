# Tip Fun MiniApp

A fun and interactive Farcaster MiniApp to **send tokens** to any address with a few clicks! Users can select from the tokens they already own and send “tips” with preset amounts ($1, $2, $5, $10) or a custom amount. The app shows a **fun message**, **recent tips**, and a **total tips counter**.

---

## Features

- Select token dynamically from your wallet  
- Quick tip buttons ($1/$2/$5/$10)  
- Custom tip amount input  
- Fun messages displayed after sending a tip  
- Total tips counter  
- Recent tips history  
- Modern design inspired by Vercel style  

---

## Prerequisites

- Node.js >= 18  
- npm or yarn  
- Farcaster account with MiniApp access  
- Tokens in your wallet on Base network (or testnet for testing)
